# 风眼 TYPHOONWATCH

JTWC tropical cyclone warnings, mirrored every 3 hours by GitHub Actions and
rendered as a bilingual offline-first PWA. Source: Japan Meteorological Agency (RSMC Tokyo). Setup and limits:
[2026-0801-typhoonwatch-setup.md](2026-0801-typhoonwatch-setup.md).

Not a warning service. For official Malaysian warnings see MET Malaysia.
