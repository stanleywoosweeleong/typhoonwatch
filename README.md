# 风眼 TYPHOONWATCH

Tropical cyclone bulletins from the Japan Meteorological Agency (RSMC Tokyo),
mirrored every 3 hours by GitHub Actions and rendered as an offline-first PWA in four languages — 简体中文, 繁體中文,
English and Bahasa Melayu. The first launch asks which one to use (as the
SkewT app does); the button at the top switches any time after. Setup and limits:
[2026-0801-typhoonwatch-setup.md](2026-0801-typhoonwatch-setup.md).

Not a warning service. For official Malaysian warnings see MET Malaysia.
