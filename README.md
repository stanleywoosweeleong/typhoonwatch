# 风眼 TYPHOONWATCH

Tropical cyclone bulletins from the Japan Meteorological Agency (RSMC Tokyo),
mirrored every 3 hours by GitHub Actions and rendered as a trilingual
offline-first PWA. Setup and limits:
[2026-0801-typhoonwatch-setup.md](2026-0801-typhoonwatch-setup.md).

Not a warning service. For official Malaysian warnings see MET Malaysia.
